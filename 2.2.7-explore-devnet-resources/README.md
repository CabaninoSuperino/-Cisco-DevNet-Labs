# 2.2.7 Lab — Explore DevNet Resources

## Цель
Изучить ресурсы, доступные на сайте Cisco Developer (DevNet): обучающие материалы, песочницы (Sandbox) и репозитории с кодом.

## Выполнение

### Part 1: Explore More Resources

#### Step 1: Start Now page / Learning Labs
На странице Start Now и в каталоге Learning Labs доступно множество обучающих материалов. В библиотеке представлено **235 лабораторных работ**, распределенных по категориям, а также доступны учебные треки (Tracks). 
В ходе исследования были найдены следующие треки:
- **NSO Basics for Network Automation**: 20 часов, от 5 до 15 лаб.
- **Cisco XDR**: 5 часов, от 3 до 14 лаб.
- **Security Workshop**: 5 часов, от 6 до 30 лаб.

Также на странице Start Now доступны видеотуториалы по Data formats (XML, JSON, YAML), APIs (REST, NETCONF, RESTCONF), Python и Ansible.

![DevNet Labs](screenshots/01-devnet-labs.png)

#### Step 2: Video course page
На сайте доступны видеомодули, включая Network Device APIs. (Количество модулей можно посмотреть в разделе Video Courses).

#### Step 3: Sandbox page
- Тип песочницы, предоставляющий приватный доступ к упакованным лабам: **Reserved Sandboxes**.
- За помощью при возникновении трудностей следует обращаться в **DevNet Support / Сообщество**.
- URL для подключения к серверу ACI в лабе ACI Simulator AlwaysOn V6: `https://sandboxapicdc.cisco.com` (или IP, указанный на странице).
- Загружать большие файлы нельзя, потому что это общая среда (shared environment) с ограниченными ресурсами, и это может повлиять на работу других пользователей.

![Sandbox ACI](screenshots/02-sandbox-aci.png)

#### Step 4: Code Exchange page
- Выбранный проект: **webex-python-sdk** (или любой другой).
- Категория: **Webex**.
- Поддержка: через **GitHub Issues** или официальные форумы разработчиков Cisco.

![Code Exchange](screenshots/03-code-exchange.png)

#### Step 5: Cisco Developer platforms
- Выбранная категория: **Networking**.
- Изученная платформа: **Cisco Meraki** (или ACI / Webex).

## Вывод
В ходе лабораторной работы я научился ориентироваться на портале Cisco DevNet: находить обучающие курсы и треки, работать с каталогом песочниц (Sandboxes) для тестирования кода на реальном оборудовании, а также искать нужные репозитории в Code Exchange.
