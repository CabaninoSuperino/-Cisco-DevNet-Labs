# Lab: Integrate a REST API in a Python Application (4.9.2)

## Обзор лабораторной работы
В данной лабораторной работе создано консольное приложение на языке Python, которое взаимодействует с REST API сервиса **Graphhopper**. Приложение выполняет следующие задачи:
1. Запрашивает у пользователя точки отправления и назначения.
2. Использует **Geocoding API** для получения точных географических координат (широты и долготы) по текстовым названиям мест.
3. Использует **Routing API** для построения оптимального маршрута с учетом выбранного профиля транспорта (`car`, `bike`, `foot`).
4. Парсит полученные JSON-ответы и выводит общую информацию о поездке (расстояние в милях/км, время в формате `hh:mm:ss`) и пошаговые инструкции движения.

---

## Структура проекта
* `scripts/` — содержит все версии разрабатываемых скриптов по шагам лабораторной работы:
  * `graphhopper_parse-json_1.py` — базовый запрос к Geocoding API.
  * `graphhopper_parse-json_2.py` — создание функции геокодинга.
  * `graphhopper_parse-json_3.py` — добавление интерактивного цикла ввода `while` и выхода (`q` / `quit`).
  * `graphhopper_parse-json_4.py` — обработка ошибок (пустой ввод, неверный ключ, пустые результаты).
  * `graphhopper_parse-json_5.py` — интеграция Routing API, расчет расстояния и времени.
  * `graphhopper_parse-json_6.py` — вывод пошаговых инструкций маршрута.
  * `graphhopper_parse-json_7.py` — финальная версия с поддержкой выбора профиля транспорта.
* `screenshots/` — папка со скриншотами поэтапного выполнения лабораторной работы.
